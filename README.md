# Classical Vision Toolkit

## Overview
This repository contains practical implementations of classical computer vision techniques developed during the CSE381 Computer Vision course.

## Topics Covered
- Image filtering and processing
- Image pyramids
- Canny edge detection
- Hough Transform
- Harris corner detection
- SIFT/ORB feature matching

## Technologies
- Python
- OpenCV
- NumPy
- Matplotlib

## How to Run
Open the relevant Jupyter Notebook using Google Colab and execute the cells in order after installing the required dependencies.

## Results
Screenshots, demonstrations, and experimental results will be added after testing.
